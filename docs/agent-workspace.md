# 产品经理 Agent 工作区

Web 首页现在是对话优先的产品经理 Agent。你可以直接粘贴飞书文档链接，或描述需要推进的工作，例如整理反馈、生成 PRD、发起评审或准备交付。

## 使用方式

1. 打开首页，输入产品 ID（可选）以绑定当前产品上下文。
2. 粘贴飞书文档链接，或从快捷任务开始。
3. Agent 会返回识别到的目标、飞书原文引用和一张待确认任务卡。
4. 选择“确认执行”后，任务会被持久化为已确认；对外交付仍应在决策工作台完成审批与导出。
5. 点击“打开工作台”查看证据、机会、PRD 版本、评审和交付记录。

## 安全边界

Agent 默认只准备工作与生成草案，不覆盖原始文档，也不会在未确认时发起评审、放行 PRD 或执行导出。飞书链接会随任务保存为可追溯的来源引用；连接、同步或权限错误会在任务状态中显示。

## 接口

- `POST /api/agent/conversations` 创建绑定产品/项目的对话。
- `POST /api/agent/conversations/{id}/messages` 提交意图并创建待确认任务。
- `POST /api/agent/tasks/{id}/confirm` 确认或忽略任务。
- `GET /api/agent/conversations/{id}`、`GET /api/agent/tasks/{id}` 恢复对话与任务状态。
